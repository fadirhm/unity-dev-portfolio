🏎️ Crazy Racing Master: Car Game

Fast-paced racing game with physics-driven vehicle control and progression system.

A competitive racing experience where players navigate spline-based tracks, avoid obstacles, and compete against AI opponents across multiple levels.

Core Gameplay

  • Spline-based racing tracks
  • Swipe controls for lateral movement
  • AI opponents for competitive racing
  • Dynamic obstacles and upside-down track sections

Vehicle System

  • Custom vehicle controller with hoverboard-style physics
  • Force-based movement and handling
  • Stable control across complex track layouts

Progression & Customization

  • Garage system with upgrades
  • Multiple vehicles, tires, and paint options
  • 50+ levels with increasing difficulty

Tools & Optimization

  • Dreamteck Splines (track path system)
  • DOTween (UI animations)
  • Odin Inspector (custom editor workflow)
  • Addressables (memory-efficient loading for tracks and skyboxes)
  • ScriptableObjects (shared configuration for vehicles and tracks)

Architecture & Performance

  • Single-scene architecture for seamless gameplay flow
  • Optimized loading to minimize interruptions
  • Object pooling to reuse runtime objects efficiently
  • Efficient memory handling for dynamic assets

My Contribution

  • Built the game from scratch as a solo developer
  • Designed and implemented vehicle controller
  • Developed racing mechanics and controls
  • Implemented progression and customization systems
  • Architected performance systems
