🎮 Bike Rider Life: Love & Dreams

Open-world delivery and story-driven gameplay experience.

A city-based open-world game where players take on delivery missions while progressing through a relationship-driven storyline. The experience combines exploration, mission-based gameplay, and interactive decision-making.

Core Gameplay

  • Delivery missions across an open city environment
  • Exploration using multiple vehicle types
  • Relationship progression through player choices
  • Activities such as gifting and shared rides

Delivery System

  • Dynamic order system accessible through in-game mobile phone
  • Players can accept delivery requests in real time
  • Mission flow includes pickup and drop-off locations
  • Continuous order updates to maintain gameplay loop

My Contribution

  • Solo developer responsible for core gameplay systems
  • Designed and implemented player controller
  • Developed vehicle systems with multiple bike variants
  • Built NPC behavior and pedestrian system
  • Implemented delivery system and gameplay progression flow

Tools & Systems

  • Mobile Traffic System (traffic simulation)
  • Easy Minimap System (navigation and map)
  • Dialogue System (interactive conversations and choices)
