🏎️ Crazy Racing Master: Car Game

Fast-paced racing game with custom physics, spline-based tracks, and scalable progression systems.

A competitive racing experience where players navigate spline-based tracks, avoid dynamic obstacles, and compete against AI opponents across 50+ levels with increasing difficulty.

Core Gameplay

  • Spline-based racing tracks using path-driven movement
  • Swipe controls for precise left/right navigation
  • AI opponents competing alongside the player
  • Dynamic obstacles and upside-down track sections

Vehicle System

  • Custom-built vehicle controller inspired by hoverboard mechanics
  • Force-based physics handling and movement
  • Stable behavior across complex and inverted track layouts

Progression & Customization

  • Garage system with upgrade mechanics
  • Multiple vehicle models, tires, and paint customization
  • Progressive difficulty across 50+ levels

Tools & Systems

  • Dreamteck Splines for track path management
  • DOTween for UI animations and feedback
  • Odin Inspector for structured and efficient editor workflow
  • ScriptableObjects for reusable vehicle and track configurations

Architecture & Performance

  • Single-scene architecture for seamless gameplay flow
  • Addressables used for efficient loading of tracks and skyboxes
  • Object pooling to reuse runtime objects and eliminate allocation spikes
  • Optimized memory usage for smooth performance on mobile devices

My Contribution

  • Built the entire game from scratch as a solo developer
  • Designed and implemented vehicle controller and physics system
  • Developed racing mechanics, controls, and gameplay loop
  • Implemented customization, upgrade, and progression systems
  • Architected performance systems for efficient runtime behavior
