🍓 Fruitscapes: Hexa Sort Game

A 3D puzzle game built around a grid-based hexagonal sorting and merging system. Developed as a solo project with strong focus on recursive algorithm design, scalable level architecture, and optimized runtime performance for smooth chain-reaction gameplay.

What I Built

  • Hex-grid placement system for organizing fruit tiles across dynamic board configurations
  • Custom recursive traversal algorithm to detect adjacent matching groups safely
  • Visited-node tracking to prevent cyclic traversal and ensure deterministic search behavior
  • Merge propagation system that resolves matched clusters back through traversal paths
  • Powerup and booster integration for complex-board recovery and strategic decision support

Core Systems

  • Grid state manager handling tile placement, stack updates, and merge eligibility checks
  • Asynchronous neighbor-evaluation tasks processing independent branches concurrently
  • Chain-reaction resolution pipeline coordinating merge sequencing and visual continuity
  • Progression loop with star rewards used to restore story-driven environment elements

AI & NPC Architecture

  • Not NPC-driven; gameplay uses deterministic rule-based puzzle-state simulation
  • Recursive node-evaluation engine replaces character AI with graph traversal logic
  • Task orchestration layer schedules branch checks to maintain frame-stable responsiveness
  • Configurable rule sets allow scalable level behaviors without gameplay code changes

Performance & Optimization

  • Asynchronous branch processing for neighbor checks to reduce single-frame compute spikes
  • Early-exit traversal guards and visited caching to avoid redundant recursive exploration
  • Data-driven level layouts supporting dynamic complexity without scene duplication
  • Mobile-focused optimization for merge, feedback, and UI update pipelines

Tools & Technologies

  • Unity (C#)
  • Custom recursive grid traversal architecture
  • Asynchronous task-based branch evaluation
  • DOTween for UI and feedback animation systems
  • Odin Inspector for structured editor workflows

My Role

  • Sole developer responsible for architecture, algorithms, and gameplay system implementation
  • Designed recursive merge detection, async traversal flow, and chain-reaction resolution logic
  • Built scalable level progression supporting 80+ handcrafted levels and boss challenges
  • Integrated boosters, progression rewards, and narrative-linked restoration systems
