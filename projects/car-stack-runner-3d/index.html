🚗 Car Stack Runner 3D: Car Games

A runner-style driving game that combines fast-paced movement with strategic resource management through math-based mechanics. Built as a solo project with a focus on scalable level systems, smooth controller behavior, and optimized gameplay loops.

What I Built

  • Custom runner car controller with stable lane movement, speed ramping, and obstacle handling
  • Math-gate system supporting multiplier, divider, addition, and subtraction stack operations
  • Stack collection pipeline with deterministic value updates and real-time UI feedback
  • Reusable obstacle modules for rapid track composition and difficulty progression
  • Level content setup tools for quick iteration across multiple challenge patterns

Core Systems

  • Continuous run loop: collect stacks → pass math gates → avoid hazards → finish conversion
  • Gate resolver architecture applying ordered arithmetic operations without frame-dependent drift
  • Progression manager scaling gate complexity, obstacle density, and target thresholds per level
  • Fail/retry flow with lightweight state resets for rapid repeat sessions

AI & NPC Architecture

  • Manager-coordinated moving obstacle logic for predictable runtime updates
  • Pattern-driven hazard behaviors with configurable timing and lane occupancy windows
  • Spawn orchestration ensuring fair challenge distribution across level segments
  • Data-defined behavior profiles to tune difficulty without code-level modifications

Performance & Optimization

  • Object pooling for gates, pickups, hazards, and VFX to prevent frequent allocations
  • Segment-based activation to reduce per-frame processing outside active player range
  • Centralized update loops replacing heavy per-object polling patterns
  • Data-driven level definitions minimizing scene duplication and maintenance overhead

Tools & Technologies

  • Unity (C#)
  • Custom runner controller framework
  • Math-gate and stack processing systems
  • Object pooling architecture
  • ScriptableObject-based level configuration

My Role

  • Sole developer responsible for architecture, implementation, and gameplay balancing
  • Built controller logic, arithmetic gate systems, and progression framework
  • Designed scalable content pipelines for rapid level authoring and testing
  • Optimized runtime systems for smooth performance across extended play sessions
