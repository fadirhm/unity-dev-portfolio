🧩 Story Puzzles: Nut and Bolts

A 2.5D story-driven puzzle game where players solve mechanical screw puzzles by strategically removing nuts and bolts from interconnected structures. Built as a solo project focused on puzzle mechanics, level systems, and responsive interactive feedback.

What I Built

  • Core unscrew interaction system for selecting, removing, and relocating connected pieces
  • Structural dependency logic to validate whether components can be detached safely
  • Powerup implementations: bomb vibration impulse, reverse undo flow, and destroy obstacle removal
  • Interactive feedback stack combining visual cues, motion transitions, and contextual UI prompts
  • Progression-linked star reward loop connected to house rebuild milestones

Core Systems

  • Puzzle state manager tracking bolt dependencies, blocked paths, and completion conditions
  • Undo pipeline for reverse actions with smooth transitional interpolation and state restoration
  • Level progression architecture supporting 80+ handcrafted levels and boss challenge stages
  • Meta progression loop using star accumulation to unlock narrative rebuild sequences

AI & NPC Architecture

  • Not NPC-driven; gameplay is based on deterministic puzzle-state simulation
  • Rule-based interaction evaluator replacing character AI with constraint-solving logic
  • Event sequencing system coordinating puzzle outcomes, effects, and progression triggers
  • Configurable puzzle behavior profiles enabling scalable level authoring without code changes

Performance & Optimization

  • Object pooling for bolts, effects, helper UI elements, and transition props
  • State-diff updates to avoid full puzzle recomputation after each interaction
  • Optimized input and feedback pipeline for consistent responsiveness on mobile devices
  • Data-driven level definitions reducing scene duplication and iteration overhead

Tools & Technologies

  • Unity (C#)
  • Custom puzzle-state architecture
  • Physics-based interaction feedback systems
  • DOTween
  • ScriptableObject-driven level and powerup configuration

My Role

  • Sole developer responsible for architecture, puzzle systems, and full implementation
  • Designed level progression, powerup mechanics, and interaction feedback loops
  • Built scalable tooling for handcrafted level production and balancing workflows
  • Integrated gameplay progression with narrative house rebuild meta objectives
