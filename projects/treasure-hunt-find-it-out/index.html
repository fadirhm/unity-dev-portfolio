🕵 Treasure Hunt: Find It Out

A hidden-object puzzle experience built around visual search accuracy, map-based progression, and increasing scene complexity. Players identify target items across diverse environments while unlocking new regions and section gates through objective completion.

What I Built

  • Core hidden-object detection loop with target list tracking and completion validation
  • Scene interaction pipeline supporting item reveal, tap feedback, and mistake handling
  • Hint assist system to guide players during high-density object search scenarios
  • Multi-map progression model with sequential map unlock conditions
  • Section-gating system where each map is split into four unlockable objective zones

Core Systems

  • Level state manager coordinating target assignment, completion checks, and progression events
  • Map unlock flow requiring prior map completion before advancing to new environments
  • Per-section unlock logic based on required item discovery thresholds within each map
  • Difficulty scaling through denser scenes, tighter object placement, and larger search sets

Performance & Optimization

  • Data-driven level/map definitions for scalable content expansion without scene duplication
  • Optimized interaction checks to keep hidden-object selection responsive on mobile devices
  • Structured asset organization to support large numbers of scene props and target lists
  • Modular content architecture enabling fast iteration across maps and unlock conditions

Tools & Technologies

  • Unity (C#)
  • Custom hidden-object search and validation systems
  • Map and section progression controllers
  • Hint and interaction feedback pipeline
  • Data-driven level configuration workflows

My Role

  • Sole developer responsible for gameplay architecture, implementation, and balancing
  • Designed core search mechanics, progression rules, and unlock-gating systems
  • Built scalable workflows for map authoring and objective configuration
  • Tuned challenge progression to balance accessibility with puzzle depth
