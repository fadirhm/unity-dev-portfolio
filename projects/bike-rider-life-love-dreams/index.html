🎮 Bike Rider Life: Love & Dreams

A city-scale open-world delivery game combining mission-based gameplay with a relationship-driven progression system. Developed as a solo project with a strong focus on scalable AI architecture, performance optimization, and continuous gameplay flow.

What I Built

  • Custom player controller with responsive movement and interaction system
  • Modular vehicle system supporting multiple bike variants
  • Dynamic delivery system with real-time mission updates via in-game phone
  • Relationship system with dialogue choices and progression mechanics
  • Centralized NPC manager handling large-scale pedestrian simulation

Core Systems

  • Delivery loop: accept → pick → deliver with continuous task updates
  • Exploration across an open-world city using multiple vehicles
  • Interaction system supporting gifting, rides, and decision-based outcomes
  • Dialogue-driven progression using structured conversation flows

AI & NPC Architecture

  • Custom NPC manager controlling all pedestrians through a centralized system
  • Spline-based pathing for lightweight and predictable movement
  • State machine-driven behavior transitions
  • Dynamic interaction system: NPCs detach, follow player, then re-integrate
  • NavMesh used only as fallback for edge-case path resolution

Performance & Optimization

  • Object pooling system for NPCs to eliminate runtime instantiation spikes
  • Distance-based NPC recycling to maintain stable performance
  • Manager-driven architecture reducing update overhead
  • Designed for scalable open-world simulation on mobile platforms

Tools & Technologies

  • Unity (C#)
  • Mobile Traffic System
  • Easy Minimap System
  • Dialogue System by Pixel Crushers
  • Odin Inspector
  • DOTween

My Role

  • Sole developer responsible for full game architecture and implementation
  • Designed gameplay systems, AI architecture, and interaction mechanics
  • Built scalable NPC systems and optimized runtime performance
  • Integrated and extended third-party tools with custom systems
