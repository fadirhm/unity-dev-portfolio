💡 Light Sort

A 2.5D puzzle game centered on rotating and sequencing connected bulbs so power flows across the full chain. The gameplay emphasizes state-based puzzle solving, precision input, and increasing logical complexity across progressively designed levels.

What I Built

  • Bulb rotation system with connection validation based on directional alignment states
  • Sequence-check pipeline that lights bulbs only when the complete chain is resolved correctly
  • Difficulty-scaling level logic introducing more branches and ordering constraints per stage
  • Smooth movement and transitions integrated with Dreamteck Splines for bulb path behavior
  • Visual feedback loop reinforcing valid/invalid states during player interaction

Core Systems

  • Deterministic puzzle-state evaluation for robust and repeatable solve validation
  • Modular level architecture supporting rapid expansion of puzzle patterns and difficulty tiers
  • Input-to-state synchronization ensuring responsive rotation behavior without desync
  • Progression loop designed around short, high-focus puzzle sessions with steady complexity growth

Performance & Optimization

  • Lightweight state checks minimizing per-frame overhead on mobile devices
  • Componentized puzzle units enabling maintainable scaling across many handcrafted levels
  • Structured editor workflows with Odin Inspector for faster tuning and debugging
  • DOTween-based UI transitions for performant and consistent visual polish

Tools & Technologies

  • Unity (C#)
  • Dreamteck Splines
  • Odin Inspector
  • DOTween
  • Custom puzzle-state and connection-validation systems

My Role

  • Sole developer responsible for gameplay architecture, implementation, and balancing
  • Designed core rotation/connection logic and progressive puzzle difficulty structure
  • Built reusable level workflows to speed up iteration and content production
  • Implemented interaction feedback and UI transitions for clear player guidance
