🏎 Crazy Racing Master: Car Game

A spline-based racing game built around fast-paced lane-switching mechanics and custom hover-style vehicle physics. Developed as a solo project with a strong focus on performance optimization, scalable level systems, and responsive gameplay flow.

What I Built

  • Custom hover-style vehicle controller with tuned acceleration, drag, and drift response
  • Lane-switching input system with buffered transitions for high-speed control stability
  • Modular upgrade pipeline for speed, handling, and boost progression
  • Vehicle customization layer for interchangeable visual and gameplay-affecting parts
  • Track obstacle framework supporting reusable hazard patterns and pacing profiles

Core Systems

  • Spline-driven race loop with deterministic path sampling for smooth lane alignment
  • Continuous progression across 50+ levels with difficulty scaling by segment configuration
  • Race state manager handling fail, retry, completion, and reward transitions
  • Economy flow integrating upgrade costs, unlock conditions, and level gating

AI & NPC Architecture

  • Spline-follow traffic agents with lane occupancy checks and speed variance control
  • Lightweight behavior states for cruising, lane change, and collision avoidance reactions
  • Spawn manager balancing active traffic density based on player speed and track segment type
  • Reusable bot configuration profiles for predictable balancing across level tiers

Performance & Optimization

  • Object pooling for traffic cars, obstacles, effects, and UI prompts to avoid GC spikes
  • Segment-based activation and culling to reduce runtime overhead on long tracks
  • Centralized update scheduling for non-critical systems to improve frame consistency
  • Data-driven level definitions reducing scene duplication and build maintenance cost

Tools & Technologies

  • Unity (C#)
  • Spline-based track system
  • Custom vehicle physics framework
  • DOTween
  • ScriptableObject-driven configuration

My Role

  • Sole developer responsible for gameplay architecture, systems design, and implementation
  • Built vehicle controller physics, progression framework, and level content pipelines
  • Designed optimization strategy for stable performance across extended race sessions
  • Balanced gameplay feel through iterative telemetry-driven tuning and testing
