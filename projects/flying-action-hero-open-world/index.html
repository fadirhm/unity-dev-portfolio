🦸 Flying Action Hero Open World

An open-world action game where players control a superhero with flight, super speed, and combat abilities. Built as a solo project with a focus on scalable AI systems, dynamic interaction pipelines, and multi-vehicle gameplay with mission-based progression.

What I Built

  • Custom superhero controller supporting grounded, flight, and high-speed traversal modes
  • Dual camera pipeline with runtime switching between third-person and first-person views
  • Combat framework with ability cooldowns, hit detection, and damage response handling
  • Vehicle interaction system for enter/exit flows across multiple drivable vehicle types
  • Mission trigger architecture for objective activation, completion tracking, and rewards

Core Systems

  • Mission manager coordinating objective states, fail conditions, and narrative progression
  • World interaction layer for civilian, enemy, and vehicle context-sensitive actions
  • Ability state router balancing movement powers with combat transitions in real time
  • Spawn and encounter control for consistent pacing across open-world activity zones

AI & NPC Architecture

  • State machine-driven NPC behaviors for patrol, alert, chase, and combat engagement states
  • Reactive AI transitions based on player distance, threat level, and mission context
  • Centralized NPC orchestration for stable large-scale simulation in active world regions
  • Role-based behavior profiles for civilians, hostile units, and support characters

Performance & Optimization

  • Object pooling for NPCs, projectiles, effects, and interaction prompts to reduce GC pressure
  • Distance-based activation and update throttling for non-critical world entities
  • Manager-based architecture to minimize per-object update cost in dense city scenes
  • Data-driven mission and AI configuration to scale content without scene-level duplication

Tools & Technologies

  • Unity (C#)
  • State machine AI architecture
  • Custom character and vehicle controllers
  • DOTween
  • ScriptableObject-driven gameplay configuration

My Role

  • Sole developer responsible for architecture, gameplay systems, and full implementation
  • Designed traversal, combat, mission, and AI systems for open-world scalability
  • Integrated vehicle gameplay with superhero abilities while maintaining control consistency
  • Owned performance profiling and optimization for stable runtime behavior on mobile devices
