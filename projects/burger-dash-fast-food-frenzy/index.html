🍔 Burger Dash: Fast Food Frenzy

A 2D time-management game focused on high-speed food assembly under strict countdown constraints. Players complete customer-specific item sequences while penalty-driven mistakes reduce remaining time, creating a fast decision-making and quick-response gameplay loop.

What I Built

  • Order assembly system validating ingredient selection against dynamic customer requirements
  • Penalty pipeline that subtracts time on invalid input to increase pressure and difficulty
  • Puzzle-level mode requiring memorization and delayed reconstruction of hidden order data
  • Boss-level mechanics supporting multi-order concurrency with rapidly shifting ingredient sets
  • Powerup systems for time extension, time freeze, and temporary auto-combine assistance

Core Systems

  • Countdown-driven gameplay loop integrating order queue, validation, and fail-state transitions
  • Level architecture supporting 100 stages with normal, puzzle, and boss difficulty profiles
  • Order comparison logic that matches expected customer sequence against player-generated output
  • Adaptive input context that updates selectable ingredient sets per active order definition

AI & NPC Architecture

  • Not NPC-AI driven; gameplay is based on deterministic order-rule evaluation
  • State-oriented order manager orchestrating request generation, validation, and completion checks
  • Configurable customer-order templates enabling scalable variation without code duplication
  • Event-driven flow control for powerups, penalties, and level outcome resolution

Performance & Optimization

  • ScriptableObject-driven level data pipeline simplifying design iteration and content scaling
  • Data-based order templates reducing hardcoded logic across 100+ gameplay scenarios
  • Lightweight state transitions optimized for responsive input and rapid UI feedback
  • Modular gameplay components enabling maintainable expansion of modes and powerups

Tools & Technologies

  • Unity (C#)
  • ScriptableObject-based level and order configuration
  • Custom order validation and gameplay state management
  • Powerup effect systems and timed gameplay controllers
  • UI feedback and transition tooling

My Role

  • Sole developer responsible for gameplay architecture, implementation, and balancing
  • Built order systems, puzzle/boss mode logic, and powerup mechanics
  • Designed scalable level-authoring workflows using ScriptableObject data definitions
  • Tuned timing, penalties, and progression for consistent challenge pacing
